# ADR-224: Bind modern null graduate claims to canonical joint evidence

- **Status:** Accepted
- **Date:** 2026-10-09
- **Deciders:** Codex autonomous session 21, ISO 2026-W41
- **Resolves:** FINDING-174
- **Extends:** ADR-018, ADR-037, ADR-080, ADR-102, ADR-158, ADR-215, ADR-222

## Context

Complete null joint verdicts can contradict intrinsically valid graduate counts,
identities, locked-holdout projections and survival. An omitted false graduate
can therefore persist as advertised zero Type-I error after authoritative merge.
Independent reproduction and the committed-artifact census precede correction.

## Decision

Only when all symbol_diagnostics carry calibration_verdict, after existing
completeness/probability/projection checks, require:

1. n_graduates equals incumbent passed-record count;
2. graduate symbols are exactly the incumbent passing-symbol set, with no
   duplicates, while retaining graduate order freedom;
3. each graduate's locked-holdout Sharpe and bar count equal its canonical
   verdict's corresponding evidence; and
4. n_clear_deflation_bar equals the number of joint passers strictly above
   ADR-018's bar at the enclosing n_symbols and their own holdout_n_bars / 252.

Legacy absent joints and nullable candidate probabilities remain supported.
Authoritative merge reconstruction inherits refusal and native consolidation
still re-judges survival at combined N. No median-history substitution or statistic
inference is permitted. Null root max_deflated_sharpe is trial-wide; graduate
margin is selected-finalist evidence with no joint counterpart. Leave those
statistics, maxima/bar identity, diagnostic history relationships and probability
rules outside this change. No estimator, threshold, fingerprint, source,
workflow or generated data changes.

## Alternatives

Independent count bounds leave contradictory complete evidence valid. Checking
only published reports leaves standalone and merge inputs unsafe. Requiring
joints on legacy measurements invents unavailable history. Forcing list order
adds identity policy beyond the membership/projection defect.

## Verification

Observe direct/JSON/unchecked-merge contradictions failing tests before code.
Protect strict equality/below/above survival, mixed histories, nonpassers,
nullable probability, graduate ordering, absent legacy joints and Hypothesis
own-history count invariants. Read-only census/round-trip all eight committed
artifacts; independently review native calibrate_gate and merge producer agreement.
Run affected consumers and the full foreground gate before individual delivery.

## Reversal

Remove conditional joint reconciliation. This reopens synthetic false-Type-I
headline contradictions and is not recommended.
