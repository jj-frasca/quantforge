Verdict: APPROVE the exact `/tmp/qf-w45-s9-roa-protocol-draft.md` reviewed in this

This approval covers the bounded contract before adoption; it is not source
acquisition authorization, code approval or an actual-result verification.

Text-only review; no imports, tests, source calls, product edits, new source
selection or outcome computation. Existing F324 source rows and reversal were
already exposed before this proposal and remain explicitly a known witness.

The contract binds actual immutable source bytes before interpretation, keeps the
existing capture observation claim and aware cutoff distinct from original public
availability, and checks source CIK against supplied history. Distinct explicit
interval assertions correctly avoid claiming original-DEI evidence absent for
FY2021/22. Exact NI and Assets groups, physical continuity, same-accession

graphs support a narrow conditional denominator-timing evaluation.

I confirm and withdraw my earlier data-triage suggestion to bind all three
AnnualFundamentals.period_end values to Assets instants. That field is sourced
from selected revenue; the known FY2020 quarter does not invalidate its genuine
closing Assets instant. The revised design uses independently attributed source
groups for ROA geometry and preserves original history unchanged. This correction
precedes adoption, tests and any new outcome computation and does not weaken a
registered source-study acceptance rule.

from attaching the new denominators to a different history without refusal.

evidence model remains an attributed claim rather than source authentication.

travels alongside it. No unrelated field, whole-history source period or PIT
certification follows.

passes them into existing finite/underflow/exact-order checks. Sharing the latest
denominator for NI and CFO preserves the accrual comparison. Evidence must travel
through actual FScore->QualityScore->FundamentalRecord production inside the
retained evaluator; no point subtraction or helper-only output is accepted.
Optional omitted-whenNone evidence and the producer's explicit nonNone-price
refusal appropriately preserve default contracts and exclude an unreviewed new
priced quality/value ranking mode. Whole-winner merge must keep one winner's
complete evidence.

for present ROA evidence should refuse nonNone value_score/combined_score, so a
direct record carrying this method cannot advertise a priced-mode claim. This
is a concrete enforcement of the fixed no-price policy, not a request to expand
scope or change existing evidence-absent records.
